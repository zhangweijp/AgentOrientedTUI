# 页面工具的生命周期

| 事件 | Runtime 行为 |
| --- | --- |
| 首次成功提交页面和启用的操作 | 建立页面挂载和操作的 activation |
| 同一页面持续提交启用的操作 | 更新 handler，沿用 activation |
| 成功禁用某项操作 | 撤销这项操作在该页的调用资格 |
| 同一页面再次启用该操作 | 分配新的 activation |
| 成功关闭或替换页面 | 撤销该挂载的工具资格和 Ref 来源资格 |
| 候选帧失败 | 保留最近有效发布并报告投影故障，等待有效提交恢复 |
| App 停止 | 拒绝新调用，按实际执行和资源状态报告清理进展 |

观察包含 App 当前全部已打开页面。Host 采用观测后才能发起调用。Runtime 检查该次观察里的 `toolId` 和接收页 `view_id`，并在进入 Worker handler 前核对接收页和 activation。显式 Ref 使用原观察里的只读值，来源页需要独立通过存活校验。

应用决定业务前置条件、外部事务和何时提交业务数据。超时后仍有执行责任时，Runtime 记录原操作及来源，直到实际完成或 Worker 退出。
